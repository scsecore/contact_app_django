Contact Management app 

A Django-based Contact Management System with user authentication, category management, contact search, CRUD operations, password reset via email, and a responsive Bootstrap UI.

## 🚀 Features
  
### Authentication
- User Registration
- User Login & Logout
- Password Reset via Email
- Secure Authentication System

### Contact Management
- Add New Contacts
- Edit Contacts
- Delete Contacts
- View Contact Details

### Category Management
- Create Categories
- Update Categories
- Delete Categories
- Organize Contacts by Category

### Search Functionality
- Search Contacts by Name
- Search by Email
- Search by Phone Number

### Responsive UI
- Bootstrap-based Design
- Mobile Friendly
- Clean Dashboard Interface
